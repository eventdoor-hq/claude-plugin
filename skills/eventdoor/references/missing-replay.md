# Diagnose a missing replay

1. **Find the broadcast.** If the user names it loosely, use `list_replays` (past broadcasts with a `from` / `to` start range) or `list_broadcasts` with `state` set to `past`, and confirm which one they mean.
2. **Ask why.** `get_replay_status` with the broadcast's id or slug answers whether it has a replay and, if not, a code and a sentence. Pass the sentence on, and what the user can do:

| Code                 | What it means                                                                                                                                              | What to tell the user                                                                                                    |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `archived`           | Its own recording is its replay.                                                                                                                           | It has one; send them to its page in the admin.                                                                          |
| `has_attached_vod`   | A video a person uploaded or attached stands in for the recording.                                                                                         | Its own recording, once archived, is in the video library.                                                               |
| `still_live`         | It is still streaming.                                                                                                                                     | The replay is made after it ends.                                                                                        |
| `queued`             | It hasn't ended, or ended minutes ago.                                                                                                                     | The archive runs shortly after it ends.                                                                                  |
| `archiving`          | The archive is running.                                                                                                                                    | Usually done within minutes.                                                                                             |
| `archiving_disabled` | Archiving is off for it.                                                                                                                                   | No replay will be made; turn archiving on before a broadcast ends next time.                                             |
| `no_end_time`        | It has no end, so there is no window to record.                                                                                                            | Set an end time, or end it in the admin.                                                                                 |
| `no_footage`         | The archive found nothing streamed to its key in its window.                                                                                               | Check the encoder was streaming to this broadcast at that time.                                                          |
| `merge_failed`       | Saving the replay failed after every retry.                                                                                                                | Ask platform support to re-run the archive.                                                                              |
| `unknown`            | Its recording was archived but isn't attached now, or the archive ran before the platform recorded why, or it was due over a day ago and recorded nothing. | The sentence says which: look in the video library for a detached recording, otherwise ask platform support to check it. |

3. **Look for the footage elsewhere** when the status says so: `list_vods` with `source` set to `live-archive` shows archived recordings and the broadcast each is attached to; `get_vod` reads one.
4. **Clips and highlights**: `list_clips` and `list_highlights` show clips and highlights cut from a broadcast; `create_highlight` and `create_clip` cut new ones once it has a replay.

Results link to the admin, never to playback. Never ask for the stream key to investigate: what was streamed shows in the status. No tool re-runs an archive or attaches a video.
